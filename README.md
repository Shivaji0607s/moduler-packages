# 🛠️ Multi-Utility Toolkit

A **menu-driven Python application** created to practice and demonstrate **Python modules, packages, functions, file handling, random operations, UUID generation, date/time operations, and modular programming**.

The project is organized into separate utility modules, making the code easier to understand, maintain, and reuse.

---

## 📌 Features

The toolkit provides several useful operations:

* 📅 **Date & Time Operations**

  * Display current date and time
  * Perform basic date/time operations

* 🔢 **Math Operations**

  * Perform mathematical calculations
  * Work with common mathematical functions

* 🎲 **Random Operations**

  * Generate random numbers
  * Select random values
  * Shuffle lists
  * Generate random samples

* 🆔 **UUID Operations**

  * Generate unique UUIDs
  * Learn how UUIDs are created and used

* 📁 **File Operations**

  * Create a new file
  * Write data to a file
  * Read data from a file
  * Append data to a file

* 🔍 **Module Explorer**

  * Explore Python modules
  * Use `dir()` to view available attributes and functions

* 🔀 **Menu-Driven Program**

  * Uses `match-case` for menu selection
  * Provides an easy command-line interface

* Easier to read
